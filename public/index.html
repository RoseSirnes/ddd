Servidor do DDD

Para encontrar amigos que usam o DDD em outros computadores, todas as pessoas precisam estar conectadas ao mesmo servidor online.

Modo local

Esse endereço só funcionará depois que o servidor central estiver publicado. Use apenas um endereço de servidor confiável. O GitHub de atualizações não é o servidor de chat.

As contas do modo local continuam guardadas no seu PC.

✳

O que é a DDD?

Um chat comunitário em tempo real. O canal #chat-global é público para todos os membros cadastrados. As conversas privadas só funcionam entre amigos.

Cuide da sua privacidade: não compartilhe senhas, documentos ou informações pessoais. Esta é uma versão inicial, ainda sem ferramentas completas de moderação.
