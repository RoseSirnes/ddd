DDD 1.3 — PESQUISA DE PESSOAS

IMPORTANTE: duas pessoas em computadores diferentes NÃO aparecem uma para a outra se cada uma está usando o MODO LOCAL.

TESTAR NESTE COMPUTADOR
1. Abra DDD.exe e crie uma conta, como Jogador_A.
2. Saia da conta e crie outra conta neste mesmo PC, como Jogador_B.
3. Entre como Jogador_A e abra Amizades > Encontrar pessoas.
4. Digite "Jogador_B" (com ou sem @). Jogador_B deverá aparecer.
5. A sua própria conta não aparece nos resultados.

PARA CONVERSAR COM AMIGOS EM OUTROS COMPUTADORES
1. É necessário publicar o servidor central DDD em uma hospedagem com HTTPS e armazenamento permanente.
2. No DDD.exe, abra Servidor do DDD.
3. Informe o mesmo endereço HTTPS do servidor central em todos os computadores.
4. Cada pessoa cria sua conta nesse servidor e poderá ser encontrada por nick.

O aplicativo já está PREPARADO para se conectar a um servidor central, mas o servidor ainda NÃO está hospedado na internet. Um repositório GitHub para atualizações é algo diferente de um servidor de chat.

O projeto contém um Dockerfile.central para implantar o backend, mas precisa de configuração de domínio, HTTPS, armazenamento persistente e controles de segurança antes de ser usado por uma comunidade aberta.
